# Atividade 4 — Recursos HTML5 (multimídia, formulário, tabela)

Página para praticar os recursos básicos do HTML5 e aplicar **SEO básico**, **CSS externo** e **responsividade**.

## Recursos HTML5 usados

| Recurso | Detalhes |
|---|---|
| Imagens | 3 `<img>` com `src` e `alt`; as duas primeiras com `width` e `height` |
| Vídeo | `<video controls width poster>` com `zoio.mp4` |
| Áudio | `<audio controls>` com fontes MP3/OGG |
| Formulário | nome, e-mail, mensagem e botão; nome e e-mail `required` |
| Links | simples, em imagem e com `target="_blank"` + `rel="noopener noreferrer"` |
| Listas | 1 ordenada (3 passos) e 1 não ordenada (3 itens) |
| Tabela | 3 colunas com `<thead>` e `<tbody>` |
| ID e classes | `id="introducao"`, `class="destaque"` (fundo amarelo claro) |
| Div | `class="caixa"` agrupando subtítulo e parágrafos |

## Melhorias (versão ampliada do relatório)

- Estrutura semântica: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Menu com links internos, galeria de imagens, tabela de tecnologias e formulário de contato
- Cartões, bordas, espaçamentos e `@media` para telas pequenas
- **SEO:** `<title>`, `meta description`, `keywords`, `robots`, `alt` nas imagens, hierarquia `h1 > h2 > h3`
