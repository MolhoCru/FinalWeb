# Atividade 3 — Estrutura semântica do HTML5

Página de blog simples para praticar **tags semânticas**, **formatação de texto**, **CSS interno e inline** e publicação no GitHub.

## Estrutura da página (`codigo.html`)

| Elemento | Função |
|---|---|
| `<header>` | Títulos `h1` a `h6` com alinhamentos diferentes |
| `<nav>` | Links âncora (`#posts`, `#lateral`, `#rodape`) |
| `<section id="posts">` + `<article>` | Conteúdo principal, como um post |
| `<aside id="lateral">` | Barra lateral com conteúdo relacionado |
| `<footer id="rodape">` | Rodapé |

## Recursos praticados

- **Formatação de texto:** `<strong>`, `<em>`, `<sub>`, `<sup>`, `<br>`
- **CSS interno** (`<style>`): classes `.center`, `.sublinhado`, `.riscado`, `.azul`, `.justificado`
- **CSS inline** (`style="text-align: ..."`) nos títulos
- **Comentários** `<!-- ... -->` explicando cada seção
- Por que semântica importa: legibilidade do código e **SEO**

## Git/GitHub

`git init` → `git add` → commit inicial ("estrutura html5 finalizada") → publicação no GitHub.
